Student Record Management System

Project Overview

The Student Record Management System is a Python-based application used to manage student information efficiently.

It allows users to add, view, update, and delete student records.

Features

- Add Student Records
- View Student Records
- Update Student Records
- Delete Student Records
- Store student details using CSV files
- Handle errors using Exception Handling

Technologies Used

- Python
- CSV File Handling
- Exception Handling
- VS Code

Student Information

The system stores:

- Student ID
- Student Name
- Department
- Year

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python main.py
